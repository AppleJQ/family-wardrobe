# 家庭智能衣橱

面向自己和家人的微信小程序，一个账号按成员管理家庭衣物。

## 当前状态

- 2026-10-22：按用户要求创建独立本地 Git 仓库，位于 `E:\个人空间\06_项目知识\my-projects\family-wardrobe`。
- 当前仅包含仓库基础文件，尚未创建小程序或后端工程，没有运行、构建或部署命令。
- 前端计划采用原生微信小程序与 TypeScript；CloudBase 或 Laravel/MySQL 后端尚未选定。
- 用户确认已添加微信服务类目“工具 → 信息查询”；本次没有进入微信后台复核审核状态。
- 尚未配置远端，尚无可用的 `origin/master`；当前 `master` 仅用于初始化基线，不创建业务任务分支。

## V1范围

- 一个账号管理多位家庭成员的衣橱。
- 逐件拍照或相册批量选图，录入衣物并人工确认信息。
- 按成员、分类、颜色、季节、收纳位置和状态查找衣物。
- 手动组合、保存搭配；衣物识别与AI文字搭配按选定服务和实际准入要求接入。
- 私有图片、数据删除和导出。

本人照片AI换装、人物照片采集、上衣/裤子/帽子试穿属于V2，不在首版实现。

## 后续开发条件

1. 确认后端路线及真实AppID、开发者权限和微信开发者工具环境。
2. 指定远端托管平台和仓库地址，将初始化基线推送为远端 `master`。
3. 创建业务任务分支前，先 `git fetch origin master`，确认工作区干净，以最新 `origin/master` 为基线。
4. 分支使用 `wjq/<类型>/<北京时间YYYYMMDD>/<任务描述>`；新worktree按现有规则放在 `E:\project\.worktrees`。
5. 微信类目审核、备案和AI识别/文字推荐的实际发布条件在提审前继续核实。
