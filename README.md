# 一方衣橱 · 家庭智能衣橱

原生微信小程序（TypeScript / WXML / WXSS），采用微信云开发 Node.js 事件云函数、文档数据库与私有云存储。

## 当前状态

- 各自微信登录，创建家庭或凭单次邀请码加入；同家庭全员管理全部衣物，不同家庭隔离。
- 衣物归属档案可新增、改名；档案与有登录权限的家庭账号分开管理。
- 单件或最多9张批量录入、失败项重试及本机恢复；名称/备注搜索与成员、分类、颜色筛选，最多20件批量整理。整批保存成功自动清理暂存并返回列表。
- 首屏由合并接口一次返回家庭、衣物和位置；短时间切回衣橱保留内容并后台同步，首次连接提供占位卡片及超时重试。
- 选图后自动智能识别名称和颜色，无额外启动按钮或二次确认，保存前可直接修改；精简录入/详情表单仅保留名称、归属、分类、颜色和备注。穿着状态的展示和操作已移除，未删除衣物均显示并可用于同成员搭配。
- 管理员可改家庭名、邀请/撤销、移出账号或移交管理权；普通家人可退出。
- 图片经服务端校验、修正方向并去除 EXIF/GPS 后私有保存；客户端不能直接读取业务数据库或存储。
- 真实云端搭配支持手动选择、替换、收藏、修改和失效提示；整装或上衣加裤子可配帽子，局部组合需明确标记。
- DeepSeek官方Flash识别与搭配已接入真实页面，选图后自动识别，详情可重新识别；建议由用户逐项应用，历史结果可查询。用户界面仅显示操作和结果，移除模型、供应商、token、用量及计费说明，服务端仍保留用量记录与重复请求保护。
- 家庭共享两级收纳位置、30天回收站与永久清理、清单/照片/搭配ZIP导出；导出过大时提示按成员拆分，不静默漏掉分页。
- 详情页仅保留“智能去背景·预览透明PNG”一个入口，固定使用腾讯云数据万象通用抠图；预览后点击“替换原图”持久保存透明PNG并更新衣物照片。私有预览缓存6小时，未知任务不自动重复计费，每账号每日最多30个新任务；替换复用已有结果，原图随衣物永久清理。
- 底部仅保留衣橱/我的家庭，搭配和设计演示入口已隐藏。真人试穿仍为本地演示，不上传人物照片。

## V1范围

- 各自微信登录，共同管理同一家庭衣橱。
- 逐件拍照或相册批量选图，录入衣物并人工确认信息。
- 按名称/备注、成员、分类和颜色查找衣物。
- 手动组合、保存搭配；衣物识别与AI文字搭配按选定服务和实际准入要求接入。
- 私有图片、数据删除和导出。

本人照片AI换装、人物照片采集、上衣/裤子/帽子试穿属于V2，不在首版实现。

## 本地开发与部署

```sh
npm ci
npm run check
npm run build:cloud
```

使用微信开发者工具打开本目录。默认首页为真实家庭衣橱 `pages/cloud/index`；`pages/index/index` 为原设计演示。Node.js 要求20.19以上。

- `npm run check`：小程序类型与资源检查；源码及素材总量限制在 1.5 MiB 内，为微信 2 MiB 主包限制预留编译空间。
- `npm run check:cloud`：云函数类型检查。
- `npm run build:cloud`：生成8个函数到 `.cloudbuild/`，生成物不提交，按受影响函数部署。
- `npm run build:release`：生成独立的小程序发布项目到 `.tmp/release/`，仅包含真实页面及其运行时依赖，移除开发演示路由与素材。版本说明见 [0.2.0交付资料](docs/releases/0.2.0.md)。

开发项目可直接点击微信开发者工具的“预览”生成二维码，包含真实衣橱和8页设计演示。透明衣物素材已缩至最长边640px并使用带透明通道的PNG调色板压缩；新增素材也需控制体积，避免把Figma原始大图直接打入主包。
