# 一方衣橱 · 家庭智能衣橱

原生微信小程序（TypeScript / WXML / WXSS），采用微信云开发 Node.js 事件云函数、文档数据库与私有云存储。

## 当前状态

- 各自微信登录，创建家庭或凭单次邀请码加入；同家庭全员管理全部衣物，不同家庭隔离。
- 衣物归属档案可新增、改名；档案与有登录权限的家庭账号分开管理。
- 单图录入、全家或指定档案/分类分页浏览、编辑、状态修改和软删除；版本冲突可重新加载。
- 管理员可改家庭名、邀请/撤销、移出账号或移交管理权；普通家人可退出。
- 图片经服务端校验、修正方向并去除 EXIF/GPS 后私有保存；客户端不能直接读取业务数据库或存储。
- 原8个Figma页面保留在“查看8页设计演示”入口。示例只存本机，不导入云端。AI、搭配收藏和试穿仍为演示，不上传人物照片。

## V1范围

- 各自微信登录，共同管理同一家庭衣橱。
- 逐件拍照或相册批量选图，录入衣物并人工确认信息。
- 按成员、分类、颜色、季节、收纳位置和状态查找衣物。
- 手动组合、保存搭配；衣物识别与AI文字搭配按选定服务和实际准入要求接入。
- 私有图片、数据删除和导出。

本人照片AI换装、人物照片采集、上衣/裤子/帽子试穿属于V2，不在首版实现。

## 本地开发与部署

```sh
npm ci
npm run check
npm run build:cloud
```

使用微信开发者工具打开本目录。默认首页为真实家庭衣橱 `pages/cloud/index`；`pages/index/index` 为原设计演示。Node.js 要求20.19以上。

- `npm run check`：小程序类型与资源检查；源码及素材总量限制在 1.5 MiB 内，为微信 2 MiB 主包限制预留编译空间。
- `npm run check:cloud`：云函数类型检查。
- `npm run build:cloud`：生成六个函数到 `.cloudbuild/`，生成物不提交。
- `npm run build:release`：生成独立的小程序发布项目到 `.tmp/release/`，仅包含真实衣橱，移除开发演示路由与素材。提审说明见 [0.1.0发布资料](docs/releases/0.1.0.md)。

开发项目可直接点击微信开发者工具的“预览”生成二维码，包含真实衣橱和8页设计演示。透明衣物素材已缩至最长边640px并使用带透明通道的PNG调色板压缩；新增素材也需控制体积，避免把Figma原始大图直接打入主包。
