小猪猪衣橱（AppID：wx80f51573314b7bd2）隐私补充说明

一、处理的数据与用途
1. 微信小程序会使用微信提供的登录身份标识，识别当前账号、执行家庭成员权限校验并保护不同家庭的数据相互隔离。小程序不向其他家庭成员展示微信 OpenID、服务端凭据或登录密钥。
2. 你可以填写家庭名称、衣物归属档案名及衣物名称、分类、状态、收纳位置和备注，用于整理家庭衣橱。
3. 你主动拍摄或选择的照片用于保存和查看衣物。上传前，小程序会提示照片用途并在需要时请求隐私授权；服务端会校验图片格式、大小和像素，调整方向、压缩并移除 EXIF/GPS 元数据。
4. 你主动请求复制家庭邀请码时，小程序会把邀请码写入系统剪贴板，方便你分享给拟加入的家人；小程序不会读取剪贴板中的其他内容。

二、家庭共享
1. 受邀请加入同一家庭后，该家庭中所有有效登录账号均可查看、添加、修改和软删除该家庭的全部衣物和衣物照片。衣物归属档案只标记衣物属于谁，不限制同家庭成员访问。
2. 邀请由家庭管理员生成，24小时有效且仅可成功使用一次。加入前会提示家庭名称及衣物共享范围。
3. 不同家庭的数据隔离。退出或被移出后，账号不能继续进行新的家庭数据访问；已经签发的短时照片链接、已打开或已下载的照片可能在失效前或本地继续存在，无法远程收回。

三、存储、保留和删除
1. 家庭衣物信息和照片保存在腾讯云开发上海环境的文档数据库与云存储中，仅通过家庭权限校验后的云端接口访问；客户端不能直接读取业务数据库或私有存储。
2. 删除衣物属于软删除，本版本暂不提供恢复或立即永久删除入口，因此不得将此操作描述为即刻永久清除。退出家庭会保留家庭衣物；退出账号不自动删除其他家庭成员需要继续使用的共享数据。
3. 你可以通过本指引公布的联系邮箱申请查阅、更正、复制或删除个人相关信息以及注销账号。运营者应核实申请人与数据范围，保护其他家庭成员的权益，依照适用法律法规处理并反馈结果。
4. 用户信息仅在实现家庭衣橱、权限安全、处理用户请求及履行法定义务所需范围和期限内保存；法律法规另有规定的，从其规定。

四、第三方与版本范围
1. 云数据库、云函数和云存储由腾讯云开发提供。平台为完成小程序运行和用户授权流程所必需的微信基础能力由微信平台提供。
2. 本版本没有衣物AI识别、AI搭配、AI生成、试穿、人物照片上传、支付或广告功能，不按这些用途收集或使用信息。
3. 不会主动向其他家庭或无关第三方公开用户的衣物资料。用户主动加入同一家庭后，按本说明第二条向该家庭有效成员共享衣物和照片。
