# 小猪猪的家 · 家庭应用改造

应用从衣橱工具调整为家庭应用，现有家庭衣橱是首个业务模块。

新增家庭首页，统一首页/我的家庭导航；家庭基础资料与衣物加载分开。我的家庭管理名称、成员档案和登录家人；按页面精简要求隐藏连接状态/刷新栏、引导副标题和邀请家人区。衣橱回收站留在衣橱模块。原衣物和成员ID、访问权限、录入/智能识别/去背景/草稿沿用。

发布项目通过`npm run build:release`生成到`.tmp/release/`，首页必须是`pages/home/index`，并包含`pages/cloud/index`。原设计演示与人物素材不打包。

本次没有修改云端服务或数据库结构。微信后台名称/简介、类目、备案和隐私资料应以实际功能核实后另行修改；生成本地发布包和扫码预览不等于已上传体验版、提交审核或正式发布。
