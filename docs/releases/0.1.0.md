# 小猪猪衣橱 0.1.0 提审资料

## 实际发布范围

家庭共享衣橱：各自微信登录，创建家庭或凭邀请码加入，建立衣物归属档案，拍照/相册选择一件衣物，手工填写名称、分类、位置与状态，查看、编辑和删除家庭衣物。

同一家庭的有效账号共同管理全部衣物，不同家庭隔离。管理员可邀请、撤销邀请、移出成员和移交管理权，普通成员可退出。衣物档案只区分衣物归属，不授予登录权限。

发布包没有 AI、试穿、搭配生成或本地设计演示入口，不采集人物照片。

## 版本说明

家庭共享衣橱首版：支持微信登录、家庭邀请、衣物单图录入与共同管理、私有照片访问和编辑冲突保护。

## 审核操作路径

1. 首页选择“创建我的家庭”，填写家庭名和个人衣物档案名。
2. 选择“添加衣物”，拍摄或选择衣物照片，填写名称及分类后保存。
3. 点击衣物查看详情，修改名称/归属/状态并保存，刷新可见。
4. “我的家庭”中新增衣物档案、生成/撤销邀请码；另一微信账号先查看邀请，再确认家庭共享范围后加入。
5. 衣物可按全家、归属档案和分类筛选；删除为家庭范围软删除，本阶段不提供恢复入口。

审核无需平台外账号密码或 AI 付费调用，审核员可用自己的微信创建家庭体验。需要双账号时使用邀请码加入同一家庭。

## 隐私声明填写依据（须与后台核实）

- 处理数据：小程序微信身份标识、家庭名称、用户主动填写的衣物归属档案名、衣物属性与用户主动选择/拍摄的衣物照片。
- 照片用途：保存衣物，并向同一家庭中经邀请加入的成员展示和共同管理。
- 选图授权：选择照片前检查隐私授权状态，提供平台隐私保护指引入口与同意/拒绝交互。拒绝后可继续浏览已有衣橱。
- 存储：腾讯云开发当前环境（上海地域）；客户端不包含服务端密钥，图片保存前去除 EXIF/GPS。
- 共享范围：仅同一家庭有效账号。已下载照片可能由家人保留，退出/移出无法远程收回。
- 删除现状：衣物为软删除，记录及图片仍可能保留于服务端；不得在隐私声明中填写“删除后立即永久清除”。
- 运营者信息、隐私联系人及有效联系方式：使用用户提供并核实的真实资料，未预填或编造。
- 后台应声明与本版本一致的照片/视频选择或相机相关处理用途；不申报本版本未使用的人像、定位、通讯录或AI功能。
