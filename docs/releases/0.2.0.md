# 小猪猪衣橱 0.2.0 交付资料

本版本集中交付录入、整理和真实衣物搭配；真人照片与试穿继续后置。当前为开发环境验收资料，不表示已上传体验版、提审或发布。

## 功能范围与操作路径

1. 衣橱支持名字/备注搜索及成员/分类/颜色筛选，筛选区移除季节、位置、状态；搜索按钮缩小，输入框占主要宽度。穿着状态的表单、标签和批量操作已移除，未删除衣物均正常显示。进入批量整理后最多20件，可统一修改或移入回收站。
2. 添加衣物可逐件拍照或选择最多9张照片，选图准备完成后直接自动智能识别名称和颜色，不需要再次确认或点击启动；识别失败可手动输入。页面及既有照片隐私提示说明第三方处理与额度。表单仅保留名称、归属、分类、颜色和备注，当前状态/季节/材质/共享及自由文本位置已移除，已有历史值不会被保存覆盖。整批成功后自动清除批次与本地照片暂存并返回衣橱，下次新增为空白；未完成项保留同请求重试，成功项不重复保存。终止失败可替换该张，新请求必须明确发起；退出家庭清除本机暂存。
3. 衣物详情可重新智能识别，建议逐项点击应用；页面移除模型名称及用量计费说明。新增录入及详情均提供“智能去背景·预览透明PNG”，固定使用通用抠图。新增录入处理当前照片，“替换原图”先采用到本机批次，保存本批时持久上传透明PNG；详情则直接更新已保存衣物。6小时内结果优先复用，替换不重新生成；处理中仅重查，失败/过期重新生成需确认。单账号每日最多30个新任务，预览按响应体积自动缩小。
4. 搭配页可手动选同一成员1～3件真实衣物，旧穿着状态不限制手动或智能搭配；完整组合为整装，或上衣加裤子，可加帽子，缺件需标记局部搭配。支持替换、收藏、编辑和删除。单品变化显示失效提示。
5. AI搭配可选成员、场合、季节、固定单品，确认后最多返回3套。历史查询沿用原任务，不重新计费；网络结果未知时明示可能已收费，另开任务再次确认。
6. 我的家庭支持两级共享位置、家庭回收站恢复/永久删除、本人在当前家庭今日任务用量，以及全家或指定成员的ZIP导出。ZIP含照片、manifest.json、衣物CSV和outfits.json。生成文件后由用户决定是否分享。单次80MB上限会提示按成员拆分，不给出不完整成功结果。

## 隐私资料需与实际后台同步

- 保持原微信身份、家庭关系、衣物属性和照片用途；新增本机录入暂存、导出文件、透明PNG预览/相册保存的用途说明。
- DeepSeek用于衣物图片识别和文字/结构化搭配推荐，发起前说明第三方处理及可能费用；家庭照片共享的同意不替代该独立确认。
- 衣物删除先进入共享回收站，30天可恢复；用户主动永久删除或超过期限后由服务端清理照片。失败清理会重试，不能声称点击即刻清除所有副本。
- 原图保留；去背景会由腾讯云数据万象处理。透明PNG在私有桶暂存供重查，有效6小时、1天生命周期清理；本机预览文件离开详情/家庭时清除。已下载、导出或分享的文件无法远程收回。
- 服务端密钥不进入客户端。AI实际账单以供应商为准，界面token计数不是人民币余额。
- 运营者真实邮箱、备案和完整AI服务对应的类目/材料，应在正式提审前根据后台重新核实。0.1.0资料中的历史状态不代表当前已通过。

## 验收范围

本地领域/页面/文件格式与并发回归、真实单微信开发链路、模拟器和发布包检查写入知识库MP-001设计实现记录。真实第二/第三微信账号共享/隔离、iOS/Android相机与弱网、真实衣物样本识别准确率仍需独立验收，不拿合成图和本地替身作通过证据。

使用 `npm run build:release` 生成 `.tmp/release`。该目录排除设计演示，递归包含真实入口所需运行时服务。只能在用户明确要求后上传体验版或提审发布。
